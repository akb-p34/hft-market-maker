# What's left out

The two code files are exact copies of what the team saved. Nothing inside them was edited.

- **Login details.** `run.py` reads the SHIFT login from a local `config.ini`, which was never in the folder and isn't here. `config.example.ini` shows the settings with placeholders.
- **`goodcbfs.py`.** SHIFT callback helpers that `run.py` never imports. It looks like SHIFT's example code, not ours.
- **Runtime logs.** The bot writes CSV logs while it runs. None are included.
- **The QF 302 course files.** That was a different team's project, so it stays private.
